# 기록형 연습 — 변호사시험

변호사시험 기록형 기출·모의고사를 실제 시험처럼 풀고, 답안을 기기에 남기는 앱.
허브(`evenoa9218-gif.github.io`) 아래 네 번째 위성 앱이다.

공유 규약(오리진·저장 계층·쟁점 ID·화면 토큰)은
[CASE_Practice의 `docs/ARCHITECTURE.md`](https://github.com/evenoa9218-gif/CASE_Practice/blob/main/docs/ARCHITECTURE.md)가 정본이다.

## 담긴 것

과목별 **55회차**(변호사시험 15 + 법전협 모의고사 40), 3과목 165회차.

| 과목 | 회차 | 채점기준표 |
|---|--:|--:|
| 공법 | 55 | 40 |
| 민사법 | 55 | 40 |
| 형사법 | 55 | 40 |

**변호사시험 15회분은 채점기준표가 공개되지 않는다** — 모의고사 40건에만 있다.
사례형과 같은 상황이고, 목록에서 회차마다 표시된다.

## 화면

- **좌우 2단** — 왼쪽 기록, 오른쪽 서면 작성. 각각 따로 스크롤한다. 기록형은
  기록이 1만~9만 자라 위아래로 쌓으면 쓰면서 보기가 불가능하다. 900px 미만에서는 1단.
- **서면별 탭** — 한 회차에 검토보고서·변론요지서처럼 서면이 둘이면 탭으로 나뉘고
  답안도 따로 저장된다.
- **임시저장** — 입력이 멎고 0.6초 뒤 자동 저장. 서면 단위(`{시험ID}::t{번호}`).

답안 전문은 **이 기기에만** 남는다(IndexedDB). 원격에는 점수·시간 같은 요약만 간다.

## 데이터 만들기

원본 hwp/txt는 저작권 자료라 저장소에 없다. 경로를 환경변수로 주고 돌린다.

```bash
set RECORD_RAW=C:\...\모의고사 기출문제, 모범답안
cd pipeline
python -X utf8 build_record_data.py
```

`data/{과목}/index.json` + `exams/*.json`을 다시 만든다.

### 작성할 서면을 어떻게 찾는가

과제 표기가 과목마다 근본적으로 다르다.

| 과목 | 표기 | 예 |
|---|---|---|
| 공법 | 로마자 번호 + 배점 | `Ⅰ. 헌법소원심판청구서의 작성 (50점)` |
| 형사법 | 문장 안, 번호·배점 없음 | "…검토보고서를, …변론요지서를 각 작성하되" |
| 민사법 | 과제 하나, 번호·배점 없음 | "…소장을 작성하시오." |

번호나 배점으로 찾으면 공법만 잡히고 나머지는 전부 실패한다. 그래서 번호가 아니라
**작성할 서면 종류**(소장·답변서·변론요지서·검토보고서·헌법소원심판청구서 등)를
기준으로 찾는다. 배점은 서면 이름 뒤에 붙어 있으면 같이 읽고, 없으면 비워 둔다.

각 회차의 `taskSource`가 무엇을 보고 뽑았는지 남긴다.

| `taskSource` | 뜻 | 건수 |
|---|---|--:|
| `points` | 배점까지 찾음 | 36 |
| `document` | 서면 종류만 찾음(배점 없음) | 124 |
| `none` | 못 찾음 — 답안칸 하나로 폴백 | 5 |

`none` 5건(공법 2014-3차·2015-1차, 민사법 변시 3회, 형사법 2014-3차·2016-2차)은
문제 표지 형식이 달라 자동으로 못 뽑았다. 앱은 답안칸 하나를 주고 "기록에서
확인하세요"라고 알린다 — **틀린 과제 목록을 지어내지 않는 쪽**을 택했다.

## 아직 없는 것

- **쟁점 태깅** — 사례형은 쟁점별 풀기가 되지만 기록형은 태깅 데이터가 없다.
  회차별 풀기만 가능하다.
- **AI 자동채점** — 사례형에는 붙어 있다([CASE_Practice `worker/`](https://github.com/evenoa9218-gif/CASE_Practice/tree/main/worker)).
  기록형은 서면 양식 채점이라 프롬프트를 따로 설계해야 한다.
- **변시 15회분 채점근거** — 채점기준표가 공개되지 않는다. 기록형 해설서를
  확보하면 사례형처럼 결합할 수 있다.
